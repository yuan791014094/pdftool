# PDF 工具箱

**免费、开源、无需注册** 的在线 PDF 工具。所有操作在浏览器本地完成，文件不会上传到任何服务器。

## 🌐 在线使用（推荐）

**直接打开网页即可使用，无需下载或安装任何软件：**

> **https://yuan791014094.github.io/pdftool/**

用手机、平板、电脑都可以，支持 Chrome、Edge、Safari、Firefox。

---

## 🛠 功能介绍

### 1. 合并 PDF
将多个 PDF 文件合并成一个。

**使用步骤：**
1. 打开网页，点击「合并 PDF」
2. 把要合并的 PDF 文件拖入虚线框，或点击选择文件（可以一次选多个）
3. 拖动文件列表中的 ↑ ↓ 箭头来调整顺序
4. 点击「合并 PDF」按钮
5. 等待完成后，点击「下载文件」

---

### 2. 拆分 PDF
将一个 PDF 按页码范围拆分成多个文件。

**使用步骤：**
1. 点击「拆分 PDF」，选择要拆分的文件
2. 设置拆分范围，例如「从第 1 页到第 5 页」作为第一个片段，「从第 6 页到第 10 页」作为第二个片段
3. 点击「+ 添加范围」可以设置更多片段
4. 点击「拆分 PDF」，分别下载各个片段

---

### 3. 提取页面
从 PDF 中挑选出指定页面，生成一个新文件。

**使用步骤：**
1. 点击「提取页面」，选择 PDF 文件
2. 文件加载后会显示每一页的缩略图预览
3. **方式一：** 直接点击缩略图来选择要提取的页面（选中的页面会显示橙色边框和对勾）
4. **方式二：** 在输入框里填写页码，如 `1,3,5-8`（表示第 1、3、5、6、7、8 页）
5. 点击「提取页面」并下载

---

### 4. 旋转页面
将 PDF 中的页面旋转 90°、180° 或 270°。

**使用步骤：**
1. 点击「旋转页面」，选择 PDF 文件
2. 选择旋转角度：90°（向右转一次）、180°（上下颠倒）、270°（向左转一次）
3. 选择应用范围：「全部页面」或「指定页面」（输入页码）
4. 点击「应用旋转」并下载

---

### 5. PDF 转图片
将 PDF 的每一页导出为图片（PNG 或 JPG 格式）。

**使用步骤：**
1. 点击「PDF 转图片」，选择 PDF 文件
2. 选择输出格式：PNG（无损，文件较大）或 JPEG（有损压缩，文件较小）
3. 选择分辨率倍率：1× 普通清晰度，2× 高清（推荐），3× 超高清
4. 点击「开始转换」
5. 转换完成后可以逐张下载，或点击「全部下载」

---

### 6. 图片转 PDF
将多张图片（JPG / PNG）合并成一个 PDF 文件。

**使用步骤：**
1. 点击「图片转 PDF」，选择图片（可一次选多张）
2. 用 ↑ ↓ 箭头调整图片顺序（每张图片对应 PDF 的一页）
3. 点击「生成 PDF」并下载

---

### 7. PDF 压缩
缩小 PDF 文件的大小，方便发邮件或上传。

**使用步骤：**
1. 点击「PDF 压缩」，选择 PDF 文件
2. 选择压缩级别：
   - **轻度压缩** — 质量基本不变，体积略微缩小
   - **均衡压缩** — 质量与体积取得平衡（推荐）
   - **最大压缩** — 体积最小，图片清晰度会有所下降
3. 点击「开始压缩」，完成后会显示压缩前后的文件大小对比

> ⚠️ 注意：压缩原理是降低 PDF 内嵌图片的分辨率。如果 PDF 内容全是文字（没有图片），压缩效果会很有限。

---

### 8. PDF 水印
在 PDF 每一页上添加文字水印。

**使用步骤：**
1. 点击「PDF 水印」，选择 PDF 文件
2. 输入水印文字，例如「仅供内部使用」「机密」「草稿」
3. 选择水印位置：居中、平铺、右下角、左下角、右上角
4. 调整透明度（越小越淡）、字号和旋转角度
5. 选择颜色（点击色块或使用颜色选择器）
6. 点击「添加水印」并下载

---

### 9. 加密 / 解密
为 PDF 设置密码，或移除已有密码。

**加密步骤：**
1. 点击「加密 / 解密」，确认选中「加密保护」标签
2. 选择 PDF 文件
3. 输入「用户密码」（别人打开文件时需要输入的密码）
4. 可选填「所有者密码」（用于限制别人编辑或打印，留空则与用户密码相同）
5. 点击「加密文件」并下载

**解密步骤：**
1. 切换到「移除密码」标签
2. 选择加密的 PDF 文件
3. 输入当前密码
4. 点击「解密文件」并下载

## ❓ 常见问题

**Q：我的文件会被上传到服务器吗？**
A：不会。所有处理都在你的浏览器里完成，文件从不离开你的设备。关闭网页后不留任何数据。

**Q：完全免费吗？**
A：是的，完全免费，永久免费，无广告，无需注册。

**Q：处理大文件会很慢吗？**
A：处理速度取决于你电脑的性能和文件大小。一般 PDF（几十页、几十 MB 以内）几秒到十几秒内完成。超大文件（几百 MB）可能需要更长时间，请耐心等待。

**Q：PDF 转图片只下载了第一页怎么办？**
A：点击「全部下载」按钮会依次下载所有页面，浏览器可能会弹出允许多文件下载的提示，点击允许即可。

**Q：压缩后文件反而变大了？**
A：原因是该 PDF 内容以文字为主，几乎没有图片。本工具的压缩方式是降低图片清晰度，对纯文字 PDF 效果不明显，有时重新编码反而会稍微增大体积。

## 💻 本地开发（面向开发者）

如果你想在本地运行或修改代码：

**环境要求：** Node.js 18 或以上版本（[下载地址](https://nodejs.org/)）

```bash
# 1. 克隆项目
git clone https://github.com/yuan791014094/pdftool.git
cd pdftool

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
# 浏览器打开 http://localhost:5173 即可看到效果

# 4. 构建生产版本
npm run build
```

**项目结构：**
```
src/
├── components/       # 通用 UI 组件（按钮、拖拽区、文件列表等）
├── hooks/            # 自定义 React Hooks
├── lib/              # 第三方库初始化（pdfjs）
├── pages/            # 各工具页面
└── styles/           # 全局样式和设计 token
```

**技术栈：**
- React + TypeScript（Vite 构建）
- [pdf-lib](https://pdf-lib.js.org/)：合并、拆分、旋转、加密等操作
- [pdfjs-dist](https://mozilla.github.io/pdf.js/)：PDF 渲染、转图片、压缩
- 纯 CSS（无 UI 框架），样式参照 Anthropic Claude 设计系统
